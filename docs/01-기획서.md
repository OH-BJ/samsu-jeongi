# 삼수전기(三手戰記) — 운명을 내미는 손

> 가제. 도트 그래픽 · 노드형 지도 · 턴제 RPG · 가위바위보 판정 · 확률(뽑기) 중심

## 1. 한 줄 소개

**모든 것을 운명의 우물(뽑기)이 정해 주는 세계에서, 가위바위보로 스킬을 발동하며 "운을 없애려는 왕"에 맞서는 이야기.**

## 2. 핵심 재미 세 가지

| 축 | 내용 | 플레이어가 하는 일 |
|---|---|---|
| **합(合) 판정** | 모든 공격·스킬·방어는 가위바위보로 결과가 갈린다. 이기면 강화 발동, 비기면 기본 발동, 지면 불발. | 적이 손마다 낼 확률(자세)을 보고 기대값이 가장 높은 손을 고른다 |
| **운명의 우물** | 직업, 동료, 무기, 방어구, 장신구, 탈것을 전부 뽑기로 얻는다. 등급은 일반부터 0.01% 초월까지. | 한정된 운명석을 어느 우물에 쓸지 정하고, 천장을 계산한다 |
| **확률 성장** | 무기 옵션은 랜덤이고, 강화는 확률로 성공하며, 일반 몬스터도 낮은 확률로 영웅급을 떨어뜨린다. | 파밍, 재련, 강화 도박, 손 성향에 맞춘 세팅 |

세 축이 맞물려야 한다. 뽑기 결과에 따라 **"이번 판의 내 손 성향"**이 바뀌고, 그 성향 때문에 전투에서 고르는 손이 바뀐다.

## 3. 게임 흐름

```
[타이틀] → [천직의 의식: 직업 뽑기] → [프롤로그]
     ↓
┌─────────────── 장(章) 하나의 흐름 ───────────────┐
│ 거점 마을: 우물(뽑기) · 대장간(강화) · 상점 · 여관  │
│      ↓                                           │
│ 노드 지도: 전투 / 강적 / 사건 / 보물 / 휴식 / 상점  │
│      ↓        (탈것에 따라 시야·이동·도주가 달라짐) │
│ 장 보스 → 이야기 → 다음 장 해금                    │
└──────────────────────────────────────────────────┘
     ↓ (8장 + 최종장)
[엔딩 3종] → [엔딩 후: 무한의 탑, 신화·초월 파밍]
```

- **노드형 지도**: 한 장에 3~4개 구역이 있고, 구역마다 노드가 10~15개다. 갈림길에서 길을 고르며, 지나간 구역은 다시 들어가 파밍할 수 있다.
- **거점 마을**은 장마다 하나씩 있고, 시설은 장이 진행될수록 늘어난다.
- **저장**: 자동 저장(노드를 지날 때마다) + 수동 슬롯 3개.

## 4. 뽑기 대상

| 대상 | 개수(목표) | 역할 |
|---|---|---|
| 직업(천직) | 18종 | 주인공의 스탯, 손 성향, 고유 스킬. 장 사이에 "전직 의식"으로 다시 뽑을 수 있다 |
| 동료 | 30종 이상 (이야기 동료 3명은 무료) | 파티 3자리. 저마다 손 성향과 스킬을 가진다 |
| 무기 | 70종 이상 | 공격력, 손 보너스, 랜덤 옵션 |
| 방어구 | 40종 | 방어, 패배 시 피해 완화 |
| 장신구(부적) | 40종 | 합 판정을 바꾸는 특수 효과 (예: 비기면 20% 확률로 승리) |
| 탈것 | 15종 | 지도 위 이동(노드 시야, 한 칸 건너뛰기), 전투 선공, 도주 확률 |

확률표와 천장은 `04-확률과성장.md`에 정리했다.

## 5. 난이도 목표

- **"중상보다 살짝 어려움"**. 구체적인 목표 수치:
  - 장 보스는 적정 장비로 처음 도전했을 때 승률이 **25~35%**가 되도록 한다. 실패하고 다시 도전하거나 파밍해서 장비를 바꾸는 것을 전제로 한다.
  - 일반 전투에서 하트(전멸)를 잃을 위험도 항상 남겨 둔다.
- **불합리함은 피한다**:
  - 확률은 항상 공개한다.
  - 천장을 둔다.
  - 운명 게이지(전투 안의 천장)를 둔다.
  - 지더라도 얻은 재화는 일부 남긴다.
- 밸런스는 시뮬레이터(`tools/sim/`)로 수천 번 돌려서 수치로 검증한다.

## 6. 플레이타임 목표

| 구간 | 시간 |
|---|---|
| 프롤로그 | 15분 |
| 1~8장 (장당 이야기 10분 + 지도·전투 15~20분) | 약 3시간 30분 |
| 최종장 + 엔딩 | 20분 |
| 파밍·사이드 (투기장, 카지노, 도감) | 1시간 이상 |
| **합계** | **약 4~5시간** (엔딩 후 콘텐츠는 별도) |

## 7. 플랫폼

- **PC 브라우저 + 휴대폰 브라우저** (가로 화면)
- 키보드, 마우스, 터치를 모두 지원한다. 화면의 모든 조작은 터치 한 번으로 가능해야 한다.
- 설치 없이 실행한다. 나중에 홈 화면 추가(PWA)와 오프라인 플레이를 지원한다.
