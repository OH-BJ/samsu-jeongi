# 05. 아트 가이드 (도트)

## 1. 방향

- **16비트 후기~현대 픽셀 JRPG 느낌**: 2.5~3등신 캐릭터, 풍부한 명암, 화려한 스킬 이펙트.
- 지난 프로토타입(16×16, 단색 위주)보다 **해상도 2~3배, 색 단계 2배**를 기준으로 삼는다.
- 등급이 높을수록 실루엣이 크고, 장식이 많고, 빛이 나게 한다. 아이콘만 보고도 등급을 느낄 수 있어야 한다.

## 1-1. 레퍼런스 조사 결과 (M1, 2026-10-15)

Chrome으로 픽시브 `#ドット絵 RPG`, `#ドット絵 キャラクター` 인기작과 Lospec을 살펴봤다. itch.io는 봇 확인 화면이 떠서 건너뛰었다. 그림은 따라 그리지 않고 기법만 정리했다.

| 관찰 | 우리 게임에 적용 |
|---|---|
| SFC 리메이크풍 전투 캐릭터는 키 약 64px, 머리가 커서 3.5등신 정도다. 외곽선은 거의 검정에 가깝게 진하다. | 아군 전투 스프라이트를 32×32 → **48×48**로 올림. 외곽선은 `#181425` |
| 금속(갑옷·금)은 4~5단계 명암에 흰 반사점 1~2픽셀을 찍는다. 금색 + 보라처럼 보색 대비를 쓴다. | 금속 램프 4단계 + W 반사점. 전설은 금, 영웅은 보라 |
| 배경을 따뜻한 단색 계열로 깔아 캐릭터를 띄운다. | 장마다 배경 색조를 하나로 통일 |
| 현대 픽셀 일러스트(뽑기 카드 감)는 차분한 기본색 위에 강조색을 하나만 쓴다. 그림자는 차갑게(보랏빛), 하이라이트는 따뜻하게 색상을 비튼다. | 도복 그림자는 청회색(G·g), 피부 그림자는 붉은 갈색(Q·o)으로 색상 이동 |
| SFC풍 UI는 어두운 남색 그라데이션 창에 흰 이중 테두리를 두른다. | UI 창 테두리 샘플에 적용 |

## 1-2. 2차 조사 — 인기 픽셀 캐릭터의 공통점 (2026-10-15)

참고: 사용자 제공 레퍼런스(픽시브 131261284, 114726334, 114726158)와 `#ドット絵 女の子` 인기작.

1. **얼굴은 작고 눈은 반짝인다**: 눈 4×5 안에 진한 윗눈꺼풀 + 홍채 2~3단계 그라데이션 + 흰 반사점 1~2개. 코는 생략하고 입은 1~2픽셀.
2. **머리카락은 크고 풍성하다**: 광택 띠(정수리를 도는 밝은 호), 앞머리 갈래, 옆머리, 길게 흐르는 뒷머리.
3. **실루엣을 만드는 소품**: 모자·무기·가방·리본 등으로 캐릭터를 한눈에 구분.
4. **진한 외곽선 + 옷 디테일**: 단추, 끈, 주름, 금테처럼 작은 장식을 촘촘히.
5. 귀여움(2.5등신)과 예쁨(4등신 이상) 사이에서 **3.3등신**으로 절충. 머리를 너무 키우지 않는다.

→ 공통 규칙을 `art/chara.js`(캐릭터 키트: 얼굴형, 눈 2종 cute/sharp, 앞머리, 옆머리, 광택 띠, 긴 뒷머리, 입 모양)로 만들어 모든 동료가 같은 규칙을 따르게 했다.

## 3. 팔레트

- 기본은 **ENDESGA 32** (Lospec 공개 팔레트), 여기에 등급 연출용 보조색 8개를 더한다.

```
#e43b44 #f77622 #feae34 #fee761 #63c74d #3e8948 #265c42 #193c3e
#124e89 #0099db #2ce8f5 #ffffff #c0cbdc #8b9bb4 #5a6988 #3a4466
#262b44 #181425 #ff0044 #68386c #b55088 #f6757a #e8b796 #c28569
보조 (등급 연출): 금 하이라이트, 신화 진홍, 초월 무지개 그라데이션 등 8색 — 샘플 작업에서 확정
```
- 캐릭터 한 명당 12~20색 안에서 쓴다. 지역마다 배경 색조를 정한다(반석: 회갈색, 쌍검: 녹색+홍등, 운포: 하늘색+흰색).

## 4. 도트 규칙

1. **빛은 왼쪽 위에서**. 명암은 3~4단계(하이라이트, 기본, 그림자, 깊은 그림자).
2. **부분 외곽선**: 바깥 테두리는 진한 색, 빛을 받는 쪽은 테두리를 밝게 하거나 생략한다. 순수한 검정(#000)은 쓰지 않고 `#181425`를 쓴다.
3. 베개 음영(가장자리만 어둡게 칠하는 방식) 금지, 계단 현상(삐뚤빼뚤한 선) 정리, 필요한 곳에만 안티에일리어싱.
4. 실루엣 테스트: 단색으로 칠해도 누구인지 알아볼 수 있어야 한다.
5. 손 성향의 상징색: 바위 = 주황·갈색, 가위 = 청록, 보 = 연분홍·흰색. 의상이나 장식에 포인트로 넣는다.

| 동작 | 프레임 | 프레임 간격 |
|---|---|---|

| 공격 | 6 | 80ms |

| 쓰러짐 | 3 | 120ms |

- 이펙트(베기, 불꽃, 빛 기둥)는 스프라이트 + 파티클을 섞는다. 등급이 높을수록 이펙트를 크게 만든다.

## 6. 만드는 방식

- 도트는 **제(Claude)가 직접 찍는다**. 방식은 다음과 같다.
  - `art/sprites/**/*.js`에 그린다. 캐릭터는 **좌표 지정 글자 격자**(문자 하나 = 픽셀 하나)로 부위별(머리·몸통·팔·다리)로 나눠 그리고, 프레임마다 부위를 다시 조합해서 애니메이션을 만든다.
  - 큰 적과 보스는 **다각형 부품 + 자동 음영(왼쪽 위 광원) + 부품별 외곽선**으로 형태를 잡는다. 균열·문양·눈빛 같은 세부는 손으로 덧칠한다.
  - 도구 모음은 `art/lib.js`(격자, 합성, 외곽선, 음영, 도형)에 있다. 게임과 갤러리, 내보내기 도구가 같은 코드를 쓴다.
  - `node tools/render-sheet.mjs all`로 **PNG 스프라이트 시트**를 `assets/sheets/`에 뽑는다. 나중에 Aseprite 같은 도구로 손볼 수 있다. (계획했던 Python 대신 Node로 바꿨다. 추가 설치가 필요 없다.)
- **레퍼런스 조사**: 첫 샘플을 만들기 전에 Chrome으로 픽시브(ドット絵, pixel art 태그), Lospec, itch.io의 게임 도트 3~5종을 살펴본다. 비율, 명암, 색 배치, 이펙트 기법을 정리해서 이 문서에 추가한다. **남의 그림을 그대로 따라 그리지는 않는다**(저작권). 기법과 감각만 참고한다.

## 7. 검수 절차

1. 제가 묶음 단위로 그린다(예: "주인공 + 무쇠 + 적 2 + 무기 아이콘 5").
2. **`tools/gallery.html`**(도트 검수 갤러리)에서 확인한다.
   - 1~8배 확대, 배경 전환(어두움/밝음/실제 게임 배경)
   - 애니메이션 재생/정지, 프레임 넘기기
   - 등급 테두리 미리보기, 팔레트 위반 표시
3. 피드백을 주시면 `docs/아트-피드백.md`에 기록하고 수정한다.
4. 상태 표시: `초안 → 검수중 → 수정중 → 확정`. 확정된 스타일을 기준 삼아 나머지를 대량으로 만든다.
