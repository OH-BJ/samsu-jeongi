# 03. 전투 시스템

## 1. 기본 구조

- 아군: **주인공 + 동료 3명** = 4명. 앞줄 2명, 뒷줄 2명. 뒷줄은 받는 피해 -25%, 근접 스킬 사용 불가.
- 적군: 1~5마리.
- 턴 순서: 속도(SPD) + 무작위(0~20%)로 정하고, 화면 위쪽에 아이콘으로 순서를 표시한다.
- 행동: **공격 / 스킬 / 방어 / 아이템 / 교대**(앞줄과 뒷줄 교체) / 도주(탈것의 도주 확률 적용)

## 2. 합(合) 판정 — 이 게임의 심장

### 2-1. 내 차례에 공격하는 경우 (공격 합)
1. 행동과 대상을 고른다.
2. **손을 고른다** (바위 / 가위 / 보). 대상 적의 **자세 확률**이 화면에 표시된다.
3. 동시에 공개해서 판정한다.

| 결과 | 효과 |
|---|---|
| **승리** | 스킬 **강화 발동**: 피해 ×1.5, 부가 효과(상태이상 등) 확정, 연승 +1 |
| **무승부** | 스킬 **기본 발동**: 피해 ×1.0, 부가 효과는 원래 확률대로 |
| **패배** | 스킬 **불발** (MP는 소모됨). 적이 일정 확률로 **역습**(약한 반격). 연승 초기화 |

### 2-2. 적 차례에 공격받는 경우 (방어 합)
- 적이 공격하면 플레이어가 **막을 손**을 고른다. 이번에도 적의 자세 확률을 보여 준다.

| 결과 | 효과 |
|---|---|
| 승리 | 피해 -70%, 30% 확률로 **반격** |
| 무승부 | 피해 -30% |
| 패배 | 피해 그대로 + 치명타 확률 +20% |

- 전투 속도를 위해 **"자동 방어"** 옵션을 둔다. 켜 두면 가장 확률이 높은 손을 자동으로 고른다.

### 2-3. 적의 자세 확률

> **변경 (2026-10-16 검수):** 손은 완전히 운으로 한다. 자세 확률과 승·무·패 확률은 화면에 보여 주지 않는다 (아래 표시 규칙은 쓰지 않음). 확률표와 패턴은 적의 성격으로 내부에만 남고, 보스의 「예고」 대사만 보인다. 하람의 「예지」는 「다음 한 판에서 지면 무승부」로 바뀌었다.

- 모든 적에게는 손별 확률표가 있다. 예: 돌골렘 → 바위 60 / 가위 20 / 보 20
- 표시되는 정확도는 상황에 따라 다르다.
  - 일반 적: 정확한 수치를 보여 준다.
  - 강적: 오차 ±10%를 보여 준다("약 60%").
  - 보스: 일부를 「???」로 가린다. **정찰 스킬/아이템/장신구**로 열 수 있다.
- 자세 확률이 **상황에 따라 변하기도** 한다. 패턴 예시:
  - 「고집」: 지면 다음 판에 같은 손 확률 +30%
  - 「들뜸」: 이기면 다음 판의 확률 분포가 무작위로 흔들림
  - 「분노」: HP 50% 이하에서 가장 높은 확률이 더 높아짐(80% 이상)
  - 「간파」: 플레이어가 직전에 낸 손을 이기는 손의 확률 +25%
  - 「예고」: 다음 손을 말로 알려 준다(진실일 확률이 따로 있다)

### 2-4. 손 성향 (빌드의 축)
- 직업, 동료, 무기에는 **손 성향**(바위/가위/보/균형)이 있다.
- 성향과 같은 손으로 이기면 추가 보너스가 붙는다(예: 바위 성향 + 바위로 승리 → 피해 +20%).
- 그래서 "적은 바위가 많은데 우리 팀은 가위 성향이다" 같은 **불리한 상성**이 생긴다. 이것을 장비를 바꾸거나 다시 뽑아서 해결하는 것이 성장의 핵심 동기다.

## 3. 보조 시스템

### 연승 체인
- 파티 전체가 연속으로 승리하면 스택이 쌓인다. 1스택당 피해 +10%, 최대 10스택(+100%).
- 패배하면 0으로 초기화된다. 무승부는 유지된다.
- 연승이 높을 때 "안전한 손"(무승부를 노리기)과 "공격적인 손" 사이에서 갈등하게 만드는 것이 목표다.

### 운명 게이지 (전투 안의 천장)
- 패배 +20, 무승부 +5. 100이 되면 사용할 수 있다.
- 사용 효과 중 택1:
  - **운명 개입**: 다음 합 1회 확정 승리
  - **다시 굴리기**: 방금 진 판을 다시 판정
- 보스전에서는 일부 패턴이 게이지를 깎는다.

### 스킬 종류
| 분류 | 특징 | 예시 |
|---|---|---|
| 일반기 | 판정 결과대로 | 베기, 화염구 |
| **필승기** | 이겼을 때만 발동하지만 매우 강하다 (피해 ×3) | 「천붕권」 |
| **안정기** | 져도 50% 확률로 기본 발동 | 「수호 방패」 |
| **손 고정기** | 정해진 손으로만 낼 수 있지만 그 대신 강하다 | 「철권(바위 고정)」 |
| **도박기** | 무작위 효과표를 굴린다(일반~대박) | 세린의 「주사위 던지기」 |
| 판정 조작기 | 적의 자세 확률을 바꾼다 | 하람의 「예지」: 적의 확률 공개 + 한 손 -20% |

### 확률 스탯
- 치명타율 / 치명타 피해 / 회피율 / 상태이상 확률 / **행운**(드롭률·옵션 등급에 영향)
- 상태이상: 출혈(가위 계열), 기절(바위 계열), 혼란(보 계열, 자세를 무작위로 만든다), 독, 굳음(흑수 전용, 행동 불가)

## 4. 계산식 (초안, 시뮬레이터로 조정)

```
기본 피해 = (공격력 × 스킬 배율) − (대상 방어력 × 0.5)
합 배율   = 승리 1.5 / 무승부 1.0 / 패배 0 (불발)
성향 보너스 = 성향과 같은 손으로 이기면 × 1.2 (+ 장비 보너스)
연승 배율 = 1 + 0.1 × 연승 스택
치명타    = 확률 시 × (1.5 + 치명타 피해 보너스)
최종 피해 = max(1, 기본 피해 × 합 배율 × 성향 × 연승 × 치명타 × 난수(0.92~1.08))
```

## 5. 적 설계 규칙

- 장마다 일반 적 6~8종, 강적 2종, 보스 1~2종.
- 장의 테마 손(반석국은 바위)을 많이 쓰되, **반드시 다른 손을 섞어** 읽는 재미를 남긴다.
- 보스는 **페이즈마다 자세 확률표를 바꾼다**. 각 페이즈의 패턴은 대사로 힌트를 준다.
- 난이도 목표(시뮬레이터 기준):
  - 일반 전투: 적정 레벨에서 전멸 확률 3~5%
  - 강적: 전멸 확률 15~20%
  - 보스: 적정 장비로 첫 도전 승률 25~35%, 장비를 갖추면 60~70%
