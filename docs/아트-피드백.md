# 아트 피드백 기록

> 검수 의견을 받으면 여기에 적고, 반영 여부를 체크한다.

## 1차 검수 (M1 첫 묶음) — 2026-10-15 제출

### 봐 주셨으면 하는 점
1. **해상도**: 전투 화면 미리보기에서 주인공(48px)과 보스(96px)의 크기 비율이 괜찮은가? 더 크게 하고 싶다면 → 아군 64×64.
2. **주인공 이로**: 싸움 자세, 머리띠, 얼굴 인상. 더 멋있게 / 더 귀엽게 등 방향.
3. **초상화**: 얼굴형, 눈 크기, 머리카락 볼륨. 정면 구도 대신 3/4 구도가 좋은지.
4. **적·보스**: 돌골렘의 각진 돌 느낌, 반석왕의 위압감, 흑수 잠식(보라 균열·손바닥 자국) 표현.
5. **무기 등급 차이**: N부터 M까지 한눈에 등급이 느껴지는지.
6. **UI·뽑기 연출**: 창 디자인, 빛기둥 연출의 화려함 정도.

### 받은 의견
- 전체적으로 나쁘지 않음.
- 보스에 위압감을 더 넣을 것.
- 동료는 레퍼런스(픽시브 131261284, 이터널리턴 팬아트 도트) 같은 느낌으로: 여성은 예쁘게, 남성은 멋있게.
  - 레퍼런스에서 읽은 스타일: 검은 외곽선 없이 부위 색의 진한 색으로 테두리, 3.5등신에 다리가 길고 늘씬함, 머리카락 4~5단계로 길게 흐름, 성격이 보이는 포즈. 그림은 베끼지 않고 스타일만 참고.

### 반영
- [x] 반석왕: 128×128로 확장. 어깨 바위 가시, 머리를 어깨 사이로 낮춤, 눈빛 후광, 흑수 불꽃(3겹 불꽃 혀), 떠다니는 잔해, 갈라진 땅. 흰 담비털 → 어두운 망토깃
- [x] 동료 하람(64×64): 긴 흑청색 머리, 무녀복, 분홍 하카마, 부적 부채. 대기 4 + 시전 5프레임
- [x] 동료 무쇠(64×64): 넘긴 은발, 날카로운 호박색 눈, 건메탈 판금 + 금 장식, 반석 문장 방패(빛이 훑음), 붉은 망토. 대기 4프레임
- [ ] 주인공 이로를 동료와 같은 스타일(64px, 외곽선 없는 방식)로 다시 그리기 → 2차 검수 결과에 따라
